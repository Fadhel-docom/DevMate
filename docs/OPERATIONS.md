# DevMate Operations

1. Work only in `Fadhel-docom/DevMate` unless the user explicitly authorizes another repository.
2. Never modify RateNest during DevMate setup.
3. Never push changes directly to `main`.
4. Use a focused feature branch for each milestone.
5. Open a pull request with a summary, test evidence, and known limitations.
6. Do not add paid services, API keys, or subscriptions before the user's first withdrawal.
7. Never claim tests, builds, deployment, or browser checks passed unless they were actually run.
8. Keep `docs/STATUS.md` updated with completed work, verification gaps, and the next exact action.
9. Keep secrets out of source code, browser bundles, commits, and logs.
10. Make Android-first instructions short and copyable.
